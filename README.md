# Computer Science & DSA Blueprints

This repository serves as a practical log and reference manual for fundamental Data Structures and Algorithms (DSA) in Computer Science. It tracks implementation progress, conceptual blueprints, and efficiency trade-offs.

## Topics Covered

- Linear Data Structures: Arrays, Linked Lists (Singly/Doubly), Stacks, Queues
- Non-Linear Data Structures: Trees (Binary Trees, BSTs, Heaps), Graphs (Adjacency Lists/Matrices)
- Algorithmic Techniques: Searching, Sorting, Recursion, Dynamic Programming, Greedy Approaches
- Complexity Analysis: Time Complexity ($O(n)$, $O(\log n)$) and Space Complexity
